# CMPS 455 — Fall 2026: Extend Sebesta Scanner

## AI-use disclosure

The assignment brief permits using large language models for specific questions, similarly to using Google, but prohibits asking a model to write the complete program.

AI was used to format the supplied assignment brief into `ASSIGNMENT_INSTRUCTIONS.md` and to transcribe the user-supplied Sebesta starter code into `scanner_ULID.c` and `front_ULID.cpp`. No implementation of this assignment's required scanner extensions was generated by AI.

## Project overview
CMPS 455 coursework extending a lexical scanner based on Robert Sebesta's *Concepts of Programming Languages*, 10th edition. The repository contains C and C++ implementations and an input file.

## Reviewer guide

- `front_C00541037.cpp`: C++ implementation.

## Local compilation
Use a C/C++ compiler on a compatible system. From the repository root:
```sh
cc scanner_C00541037.c -o scanner
./scanner
c++ front_C00541037.cpp -o front
./front
```
Keep `test data.in` in the working directory. No automated test suite or hosted app is claimed.
